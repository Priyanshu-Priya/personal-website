## A Quick Code Example

Here's a simple TypeScript function I use everywhere:

```typescript
function formatDate(date: Date): string {
  return new Intl.DateTimeFormat('en-US', {
    year: 'numeric',
    month: 'long',
    day: 'numeric',
  }).format(date);
}

// Usage
const today = formatDate(new Date());
console.log(today); // "January 10, 2026"
```
